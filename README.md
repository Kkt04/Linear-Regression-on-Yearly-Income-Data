# 📈 Linear Regression on Yearly Income Data

This project demonstrates how to perform **Linear Regression** using Python’s `scikit-learn` library to predict income based on the year. It uses historical data (1970–2016) and visualizes both the actual data points and the regression trend.

---

## 🧰 Requirements

Install the required Python libraries before running the script:

```bash
pip install pandas numpy matplotlib scikit-learn
